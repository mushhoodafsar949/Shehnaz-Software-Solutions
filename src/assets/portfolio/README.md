# Portfolio Images

This directory contains screenshots/images of websites developed by Nest Tech AI Solutions.

## Required Images

Please add the following images to this directory:

1. **fuolk.jpg** - Screenshot of https://fuolk.com
2. **hostech.jpg** - Screenshot of https://www.hostech.app/
3. **ezwayhouses.jpg** - Screenshot of https://ezwayhouses.com/
4. **gattex.jpg** - Screenshot of https://www.gattex.com/
5. **barkkah.jpg** - Screenshot of http://barkkah.sa/
6. **alkoblan.jpg** - Screenshot of https://alkoblan.com.sa
7. **musan.jpg** - Screenshot of https://musan.shop

## Image Specifications

- **Format**: JPG or PNG
- **Recommended Size**: 1200x800px or similar aspect ratio (3:2)
- **File Size**: Optimized for web (under 500KB per image)
- **Content**: Full website screenshots showing the homepage or key pages

## How to Add Images

1. Take screenshots of each website (you can use browser extensions or tools like Screenshot API)
2. Save them with the exact filenames listed above
3. Place them in this `src/assets/portfolio/` directory
4. The images will automatically appear on the home page

## Fallback

If an image is missing, a placeholder with a gradient background and globe icon will be displayed.
